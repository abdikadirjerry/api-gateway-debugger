# API Gateway & Traffic Inspector (`api-gateway-debugger`)

An enterprise-grade API testing, microservice routing simulation, and traffic inspection workspace built with React, TypeScript, and Tailwind CSS.

## Features

- **Microservice Route Selector:** Browse gateway routes across Auth, User Profiles, Payment Billing, and Telemetry ingest.
- **Interactive Request Workbench:** Configure JSON payload bodies and inspect gateway headers.
- **Latency Waterfall Timeline:** Detailed telemetry breakdown of DNS, gateway authorization, and upstream execution.
- **Strict TypeScript Types:** Complete interface mapping for routes, requests, headers, and responses.

## Setup & Running

1. Clone repository & install dependencies:
   ```bash
   cd api-gateway-debugger
   npm install
   ```
